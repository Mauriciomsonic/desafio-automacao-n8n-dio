# 🔄 Guia de Atualização Contínua na Hostinger (projetohandmadetemplates.online)

## Procedimento de Atualização:
1. Gere o novo build: npm run build
2. Envie o novo pacote para a pasta public_html no Gerenciador de Arquivos.
3. Extraia substituindo os arquivos antigos.
4. No hPanel, vá em Desempenho > Cache (LiteSpeed) e clique em "Purgar Todo o Cache" (Flush Cache).
5. Recarregue no navegador com Ctrl + F5 para testar.
